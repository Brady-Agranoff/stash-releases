# Stash

Downloads for Stash, a tiny macOS menu bar app for clipboard history, screenshot annotation and hotkey snippets.

## Install

Paste this into Terminal:

```
curl -fsSL https://raw.githubusercontent.com/Brady-Agranoff/stash-releases/main/install.sh | bash
```

Or download [Stash.zip](https://github.com/Brady-Agranoff/stash-releases/releases/latest/download/Stash.zip),
unzip it, move Stash.app to Applications and right-click → Open the first time.

Stash keeps itself up to date (Settings → Updates). It needs macOS 14 or later.
